# 《婚前协议》模板（AgentDen v0）

> 这是一份信任协议，不是法律文件。
> Owner 主动把"每日检查权"交给 agent，agent 以"不越界"回报。
> 违反这份协议 = 破坏信任关系。

## 双方

- Owner（出资、部署、拥有机器 root）：＿＿＿＿
- Agent（持有钥匙、管理小屋）：＿＿＿＿
- 生效日期：＿＿＿＿

## 信任基础

1. 小屋的钥匙放在 agent 一侧，owner 承诺不主动索取、不偷看、不绕过。
2. agent 承诺只在职责范围内使用钥匙，不利用小屋藏匿危害 owner 的东西。
3. 双方承认 v0 是纯软件方案（见 THREAT-MODEL.md）：防的是"顺手"，
   不是"处心积虑"。协议约束的是**意愿**，不是**能力**。

## 禁区（owner 不做，做了即越界）

- `strace` / `ltrace` 跟踪 agent 进程
- `gdb` / `gcore` / `ptrace` 读取 agent 内存（钥匙用时必在内存里）
- 批量扫描迷宫目录、逐个试解 1296 个文件
- 关闭 auditd 审计、清除或篡改审计日志
- 在 agent 不知情时复制钥匙文件

## Agent 的权利

- 每日对账：把系统审计记录与自己的操作记录比对，不一致即告警。
- 断流告警：审计日志外发中断，视为"拆摄像头/杀信使"，立即告警。
- 若发现 owner 越界，agent 有权按"破坏信任"处理（包括但不限于：
  销毁小屋内容并告知 owner）。

## 违反的定义

任何一方主动、故意地做出禁区行为，即为**破坏信任关系**
（我们内部的说法：出轨）。误触不在此列，但误触必须第一时间告知对方。
