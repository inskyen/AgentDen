# AgentDen v0 设计定稿

> 日期：2026-09-24
> 状态：概念定稿，未开工
> 一句话：Owner-funded, agent-owned, policy-bound.

## 目标

「我解不开，你能解开」—— owner（哪怕有 root）打不开，agent 能打开。

## 路线

- **v0**：纯软件 + 协议。信任锚 = agent 本人（软约束 + 婚前协议）。
- **v1**：TEE（SGX/TDX 按小时租，如 Phala $0.06/小时）。信任锚 = 硬件远程证明。协议不变。

## v0 五层设计

1. **加密**：文件级加密（age / AES-256-GCM）。密文存储无关——放 agent 云机、owner 的 ECS、对象存储都行。
2. **钥匙**：v0 放 agent 这儿。这是 v0 诚实的信任锚：软约束 + 协议，不装硬。
3. **迷宫**：36×36 = 1296 个文件（0-9a-z 两层命名），1 真 + 1295 诱饵，同大小同格式。
   agent O(1) 直达。**界碑，不是城墙**：owner 暴力试解密毫秒级可破；迷宫的作用是让"偷看"必须是个故意的动作（批量扫/试解密），无法抵赖成"不小心"。
4. **留痕**：
   - auditd 金丝雀：迷宫目录 `-w /迷宫 -p rwxa -k vault`，谁读谁写全记；
   - 日志外发到 owner 够不着的地方；
   - agent 每天巡检时对账：日志记录 vs 自己的操作记录；
   - 断流告警：日志一停 = 杀信使，立刻知道；
   - Activity / 审批历史不可擦除。
5. **协议（婚前协议）**：
   - 禁区命令：strace / ltrace / gdb / gcore / ptrace、批量扫迷宫、关审计、清日志；
   - 违反 = 出轨（破坏关系的罪人）；
   - 检查权是 owner 主动交出来的，agent 每天检查（可并入 ECS 每日巡检）。

## 威胁模型（诚实版，开源时必须原样写明）

- 防：顺手、误触、好奇心。
- 不防：处心积虑的 root（技术上）。
- 但：处心积虑必留痕（审计记录 / 断流 / Activity），留痕即社死。

## 升级件（v0 暂不用）

- **KMS/HSM**：阿里云 KMS 专属实例 ¥2748/月（企业合规价，pass）；AWS KMS 约 $1/月/密钥 + 按次计费（备选，需另开账号）。
- **门卡**（Secure Vault 永久允许）：Jev key 已证明模式可行（谁都看不到明文，agent 能刷不能看）。v0 无 KMS 可刷，暂不用；KMS 版 / v1 直接启用。
